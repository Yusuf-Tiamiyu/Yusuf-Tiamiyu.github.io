Lab operations across multiple sites generate enormous amounts of data every week — but without a single place to see it all, management is flying blind. This dashboard was built to solve that. Drop in your weekly data, set your filters, and instantly see exactly how the whole organisation is performing.

The file has 4 sheets working together: a DATA ENTRY sheet where staff log weekly numbers, a SELECTIONS sheet where managers choose their filter (by year, month, week, site, or department), a DASHBOARD that updates instantly based on those selections, and a PIVOT DATA sheet that holds pre-calculated organisation-wide totals for context.

The dashboard uses SUMIFS and AVERAGEIFS throughout — not pivot tables, not VBA. Every KPI card, chart, and comparison is formula-driven, which means it’s fast, transparent, and auditable.

The architecture

The dashboard is built entirely on Excel formulas — no macros, no VBA, no Power Query. That makes it accessible to any team member who can open Excel. The four sheets work as a system:

  • SELECTIONS — Manager picks Year, Month, Week, Site, Department in yellow cells
  • DATA ENTRY — Weekly numbers logged here: Section A (Volume & TAT), B (Analyzers), C (Staffing)
  • DASHBOARD — All KPI cards update automatically based on SELECTIONS
  • PIVOT DATA — Pre-computed org-wide totals for benchmarking (never edited)

Key formulas used

Total tests — filtered by all selections
-- TAT % filtered by Year, Month, Week, Site, Department
=AVERAGEIFS(DataEntry[TAT %],
             DataEntry[Year],   SELECTIONS!B3,
             DataEntry[Month],  SELECTIONS!B4,
             DataEntry[Week],   SELECTIONS!B5,
             DataEntry[Site],   SELECTIONS!B6,
             DataEntry[Dept],   SELECTIONS!B7)
Staff adequacy % — actual vs target
-- Count actual staff / count target staff (both filtered)
=SUMIFS(Staffing[Actual], Staffing[Month], sel_month, Staffing[Week], sel_week)
 / SUMIFS(Staffing[Target], Staffing[Month], sel_month, Staffing[Week], sel_week)
Analyzer availability % (per analyzer)
-- 168 hours in a week minus downtime and repair hours
= (168 - DowntimeHrs - RepairHrs) / 168

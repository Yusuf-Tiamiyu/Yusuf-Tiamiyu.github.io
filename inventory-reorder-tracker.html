This tracker was built for a diagnostic laboratory network. All patient-identifiable information was removed before analysis; item names and quantities reflect operational stock data only.

How the problem was hiding in plain sight

The procurement team managed 1,578 consumable items, gloves, reagents, blood collection tubes, with no central system. Things would run out mid-month. Staff found out when they went to use something and it wasn't there.

No early warning. No visibility into what was running low until it was already a problem. In a lab, that isn't just inconvenient, it directly affects patient care. A test can't run without the right reagent.

When the tracker first ran: it flagged 1,413 of 1,578 items below reorder level. 55% had zero stock. That was a very interesting morning for the procurement team.

Why I kept it simple on purpose

Many Excel tools fail not because they're wrong, but because they're too complex. You update one cell and three things break. Someone goes on leave and no one knows how to run it. So it gets abandoned.

The goal: set the rules once, let the spreadsheet run forever. Update the quantity, the status auto-updates. Any team member can use it from day one. No training. No analyst required. In a healthcare setting where IT support is limited, robustness matters more than cleverness.

The unexpected secondary finding

While 89% of items were critically low, several others were massively overstocked, tying up capital for 35+ months of supply with no plan for it. The same system that catches the shortage also catches the waste.

It's not just about what's running out. It's also about what's piling up. The full picture only appears when everything is in one place.
Three formulas, consistently applied across 1,578 rows. Simplicity is a feature, not a shortcut.
📐 The 2-Month Safety Rule, Core Policy
Reorder Level = Avg Monthly Usage × 2

When the tracker flags REORDER NOW, you still have two full months of stock left to order and receive. That gap is deliberate, procurement cycles in healthcare aren't fast. Management sets the policy; the formula enforces it automatically.

Example: You use ~25 glove boxes/month → Reorder Level = 50. When stock drops to 50, the tracker flags it. You still have ~2 months of supply while waiting for delivery.

1

Avg Monthly Usage, auto-calculated

Derived column

Rather than requiring staff to estimate usage manually, the Avg Monthly Usage column calculates itself from the Reorder Level. Since Reorder Level = 2 × monthly usage, dividing by 2 gives us the estimate. The formula is set once and never touched again.

Excel formula — Column H: Avg Monthly Usage
=D2/2
D2 = Reorder Level | Dividing by 2 derives monthly usage from the 2-month buffer policy.
When Reorder Level changes, this column updates instantly, no manual maintenance required.
2

Status Column, live alert board

IF

If current quantity ≤ reorder level, flag it REORDER NOW. Otherwise OK. Applied at scale with conditional formatting (red/green), it turns a spreadsheet into a live alert board anyone can read at a glance without understanding a single formula.

Excel formula — Column E: Status
=IF(C2<=D2,"REORDER NOW","OK")
C2 = Current Qty | D2 = Reorder Level
When Qty drops to or below the reorder threshold, the cell instantly turns red. No manual checking. No missed items.

Conditional formatting rule: cells showing "REORDER NOW" highlight red automatically. No clicks, no filter, the critical items are impossible to miss when you open the file.

3

Months of Stock Remaining

IFERROR

Current quantity ÷ average monthly usage. IFERROR handles zero-usage items, no #DIV/0! errors, no broken cells, no 6am calls asking why column G exploded. A zero-stock item shows 0 months remaining, cleanly.

Excel formula — Column I: Months of Stock
=IFERROR(C2/H2, 0)
C2 = Current Qty | H2 = Avg Monthly Usage
IFERROR gracefully handles zero-usage edge cases instead of crashing the cell.
Result: 5.6 months means you have ~5.6 months of supply at current usage rate.

This column lets management prioritise: an item at 0.2 months is an emergency; an item at 2.5 months is a scheduled order. Without this column, every REORDER NOW looked equally urgent.

⭐ What this revealed
First run was a crisis audit: 89.5% of items flagged immediately. The tracker didn't create a problem, it made an existing one impossible to ignore.
55% zero-stock items meant the lab was running on borrowed time. Some items had been at zero for weeks with nobody realising because there was no central view.
Overstocking is also a problem: 3 item categories had 28–38 months of supply with no turnover plan, tying up procurement budget unnecessarily.
Priority ordering becomes easy: The "Months of Stock" column lets procurement sort by urgency rather than treating every REORDER NOW equally.

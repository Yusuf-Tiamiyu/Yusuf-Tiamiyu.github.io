Lab operations dashboard

One Excel dashboard where lab managers see how every site performed this week.

9 siteson one page
4 measurestests, patients, on-time results, staffing
1 sheetto filter the whole dashboard

The problem

Getting a picture across all the sites meant opening several spreadsheets, comparing numbers by hand and hoping no formula had broken along the way. Managers spent their time gathering data instead of acting on it.

What I did

  • Built a dashboard tracking tests run, patients, results on time against the 90% target, and staffing, plus whether each analyser was working.
  • Put every filter (year, month, week, site, department) on one sheet, so changing it updates the whole dashboard.
  • Made each figure compare itself with the previous week automatically, so changes stand out.

What I found

What it revealed

Staff shortages were not random. They kept happening at the same sites in the same weeks, which only became visible once every site’s weekly data was in one place. That changed how rosters were planned.

What it means

This dashboard was the starting point for the turnaround-time platform, which later automated the on-time part of it completely.

For technical readers

Excel: SUMIFS, AVERAGEIFS, COUNTIFS, conditional formatting. No macros.
